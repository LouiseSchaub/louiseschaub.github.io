What does each representation cost?

Rough leading-order counts: the monomial form needs one solve of the Vandermonde system (about N³/3 operations for N nodes, Theorem 2.6), then about N multiplications per point with Horner's scheme. The Lagrange form (3.9) needs no setup, but about 2N² multiplications and divisions per point.

What to try

Drag a data point. In the Lagrange view only the term of that point changes, and its coefficient is the new value. In the monomial view all coefficients cₖ change, because they come from solving a linear system.

Add the point (4, 9). It already lies on the parabola, so the interpolant does not change: c₃ = 0. In the Lagrange view, though, every basis polynomial is new.

Cost. With the sliders, find how many evaluation points it takes until solving the Vandermonde system once pays off. It is only about N/6, so for almost any real use the monomial form is cheaper to evaluate. Its weakness is accuracy, not speed: for many nodes the Vandermonde matrix becomes extremely ill-conditioned (Chapter 2).
