Building a Natural Cubic Spline

On each interval [xᵢ₋₁, xᵢ] the spline is a cubic pᵢ(x) = a₀⁽ⁱ⁾ + a₁⁽ⁱ⁾(x − xᵢ) + a₂⁽ⁱ⁾(x − xᵢ)² + a₃⁽ⁱ⁾(x − xᵢ)³. The four conditions before Theorem 3.6 fix all 4n coefficients. Drag the data points and watch the coefficients, the system (3.12) and the conditions at every node.

What to try

Look at s″. It is a continuous, piecewise linear function that is 0 at both ends: the natural boundary conditions. Each piece contributes one straight segment from 2a₂⁽ⁱ⁾ − 6a₃⁽ⁱ⁾h (left end) to 2a₂⁽ⁱ⁾ (right end).

Turn on "Algorithm 5 as printed". If a₃ and a₁ are computed before the system for a₂ is solved, they use a₂ = 0. The pieces then no longer meet: the spline jumps at the nodes, and the condition table turns red. Solving (3.12) first fixes it.

Compare with the polynomial. Drag one point far up. The spline only changes noticeably near that point, while the polynomial of degree n reacts on the whole interval. This is the subject of Exercise 4.
