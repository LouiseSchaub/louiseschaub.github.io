The Lagrange Basis

Each basis polynomial Lᵢ(x) = ∏ⱼ≠ᵢ (x − xⱼ)/(xᵢ − xⱼ) is 1 at its own node and 0 at all other nodes, so the interpolant is simply p(x) = Σ yᵢ Lᵢ(x) (Definition 3.3, Theorem 3.5). Drag the nodes in the top plot and the data points in the bottom plot.

What to try

Drag a data point. Only the bottom plot changes: the Lᵢ depend on the nodes alone, not on the values yᵢ. Tick "show the terms yᵢ Lᵢ(x)" to see how the point scales its own term.

Drag a node. Now every Lᵢ changes, because each one contains all nodes.

All ones. With yᵢ = 1 the interpolant is the constant 1, so Σᵢ Lᵢ(x) = 1 for every x. Tick "show Σᵢ Lᵢ(x)" to see it.

Write-up example. Nodes 0, 1, 2 with y = (1, 3, 2) give p(x) = 1 + 3.5x − 1.5x², the same polynomial as the Vandermonde system (3.8).
