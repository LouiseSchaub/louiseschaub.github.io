Composite Rules and Their Convergence

A composite rule splits [a, b] into N intervals of width h = (b − a)/N and applies the trapezoidal or Simpson's rule on each piece (Definition 4.3). Each node then gets a weight. Watch how the error falls as N grows, and compare it with the error bounds of Example 4.5.

What to try

The weights (Exercise 2a). With the trapezoidal rule the weights are 1/2, 1, …, 1, 1/2 (times h). With Simpson's rule every pair of intervals is one panel, and the weights become 1/3, 4/3, 2/3, 4/3, …, 4/3, 1/3: interior even nodes belong to two panels. All weights together are b − a = 2.

Odd N with Simpson. Set N to an odd number. One interval is left over, and the weight pattern no longer fits. The page then applies the pattern blindly, as a loop over the node index would, and the result is wrong. This is what happens in Exercise 4 if N is computed from a bound with ceil() and not rounded up to an even number.

Convergence (Exercise 3c). In the log–log plot the trapezoidal error falls with slope −2 and Simpson's with slope −4: doubling N divides the error by 4 and 16 (Example 4.5). For large N Simpson's error stops at about 10⁻¹⁵ and then fluctuates: this is rounding error (Chapter 2), not the method.

The bounds (Exercise 4). Choose (x + 4)⁻¹. The dashed lines are the bounds of Example 4.5. The trapezoidal bound and Simpson's bound with 1/180 lie above the error, as they must. The dotted line is Simpson's bound as printed in the notes, with 1/2880: it lies below the actual error, so it is not a bound. The constant 1/2880 belongs to the panel width 2h, not to the node spacing h.
